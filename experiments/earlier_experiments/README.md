# Earlier experiments (kept for reference)
Results from the first phase: command parsing (e0), preliminary factual sets (e1_prelim), the labeling set of the first run (e1_v2_1074, whose folder name keeps the original count; the final set has 1,071 questions), the server-based controller run (e2_controller) and the battery drain test (e3_battery, Raspberry Pi 4).
Energy values in `e2_controller` use the corrected window-clipped integration (see `../../docs/ENERGY_CORRECTION.md`).
Large raw power logs of the battery test are not included.
